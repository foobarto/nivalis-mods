# Changelog

## 0.1.3 — First public test release

- Place player-owned furniture on the docked player boat through native controls.
- Track up to 128 relative attachments with exact-save metadata.
- Use current helm occupancy for editing eligibility.
- Preserve ownership evidence while newly selected furniture initializes.
- Enable scoped boat-deck surface queries without replacing native collision rules.
- Support native pickup menus, cancel/storage, and decorating/store HUD hints.
- Require Steam build 25680465 and validate managed bindings before hooking.

Placement, rearrangement, pickup, storage/cancel and hints have been confirmed
in-game. Sailing, recall, scene transitions and save/reload persistence remain
pending end-to-end validation.
